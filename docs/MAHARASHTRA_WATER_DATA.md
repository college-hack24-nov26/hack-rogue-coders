# Maharashtra water-data catalogue and map

Verified on 3 November 2026, Asia/Kolkata. This inventory supersedes the earlier four-resource spot check. It covers accessible Maharashtra-labelled NWIC resources across publishing agencies, not a claim that every village has a complete water balance.

- 173 government record APIs checked: 75 current-period and 98 historical resources.
- 50 current resources contain usable dated measurements with coordinates; the others are empty or unsupported by the checked parser.
- 2,525 unique agency/name/coordinate monitoring locations across 34 reported districts; 965 have a reading within 48 hours at audit time.
- Official reference map: 2,140 river features, 12,115 canal features and 3,116 reservoir features intersecting Maharashtra or its bounding region. Features may cross state borders. These counts are map features, not independently verified water supplies.
- No 2011 Census population, demand or infrastructure baseline is used. Current map readings use the latest published records; training exports enforce dates from 2021 onward.
- Source map survey dates are unspecified. Latest published archives are transformed to EPSG:4326 and generalized by 0.0002 degrees for display. Original archives and hashes are retained; reference geometry is excluded from prediction inputs.

## What is live, and what is available for training

| Data family | Current observations | Historical training access |
|---|---|---|
| Groundwater (Maharashtra GW, CGWB) | Working record APIs; latest verified measurements 2 November 2026 | Historical resource APIs and CSV links indexed; 2021-2025 Maharashtra GW archive already exists locally |
| River levels (Godavari, Krishna, Tapi, west-flowing basins) | Working record APIs; recent telemetry reaches 2 November; some manual resources are empty/stale | Historical basin CSVs and APIs indexed |
| River discharge (CWC, Maharashtra SW) | CWC reaches 2 November; the checked Maharashtra SW manual resource stops in September | Separate historical resource links indexed |
| Rainfall, temperature, humidity, wind, solar radiation, pressure | Working observational APIs; some reach 2 November and some are older/empty | Historical series indexed; these are observations, not forecasts of future weather |
| Reservoir/canal levels and releases | Selected assets have current measurements; Pench/Totladoh have older readings | Historical resource links indexed; original units retained |
| River/canal/reservoir geometry | Latest published official file downloaded; survey date unknown | Geographic reference only, excluded from prediction inputs |
| IMD future rainfall forecasts | Endpoint returned HTTP 401: API key required | Historical forecast issue-time archives not verified |
| Drinking-water pipelines, DMA flows, tank levels, village deliveries | No verified statewide public operational feed | No complete village training target established |

## Using the app

Open Admin -> Maps. Explore Maharashtra or choose a district. Search the current imported village directory, then select a village. Source cards show measurements, units, dates and official citations. Layer filters include groundwater, river, canal, reservoir, weather, water quality and pipeline geometry.

Village map responses separate reviewed supply/source connections from geographic or district context. Monitoring-site names and proximity do not create supply links. When village coordinates are missing, the map shows district context and omits the village pin. Missing pipeline data is stated explicitly. Recorded allocations without coordinates appear below the map.

System administrators can use **Refresh from official sources**. The job retrieves changed current resources and publishes a new local snapshot after validation. Other users can reload the published snapshot. Refresh is on demand, not a continuously scheduled task.

**Live & training data** contains every indexed resource, its API status, actual latest observation when checked, row/station count, and CSV/API/source links. All 98 indexed historical files have now been downloaded and calendar-date-profiled, producing 39,240,902 candidate rows from 2021–2025. Historical collection has a resumable downloader and filtered candidate exporter. See `data/water/history-collection.json` for actual downloaded/profiled/failed counts. Downloaded data is not quality-approved. The indexed historical source files total approximately 6.73 GB.

## Reproduce or prepare training records

```powershell
uv sync
uv run python -m scripts.sync_water_data --geometry
```

Refresh observations only (reuse published geometry):

```powershell
uv run python -m scripts.sync_water_data
```

Export an identified resource with no observations before 2021 and a chronological cutoff (current year held out by default):

```powershell
uv run python -m scripts.export_water_training RESOURCE_UUID --output data/raw/training/selected-resource.csv
```

Use resource IDs from `data/water/catalogue.json`. Direct source downloads can contain earlier years; do not bypass the filtered exporter when assembling training inputs. Exports keep original columns/units and a hash/provenance receipt. They do not train, validate or approve a model.

Download all indexed historical raw resources only when the storage/bandwidth cost is intended:

```powershell
uv run python -m scripts.sync_water_data --history
```

## Reviewed pipeline overlays

Authority-supplied GeoJSON can be installed as `data/water/reviewed-network.geojson`. Each feature needs `properties.id`, `name`, `kind` (`pipeline` for drinking-water lines), `source_url`, `village_ids`, `relationship: reviewed_connection`, and `connection_evidence`. Use genuine surveyed geometry; include observation/review dates. The file is operator-managed, not generated from nearby stations. Alternatively, reviewed geography crosswalks can list `water_asset_ids` matching map source IDs.

## Validation and limits

- TypeScript and both web builds pass. Two browser checks cover village selection, filters, pipeline geometry with labelled fixtures, historical links, and the actual Satara snapshot.
- 22 focused map/auth/security/export tests passed. The full backend run had 79 passes and 11 failures due to absent older research/residual/multiyear/seasonal model artifacts; the new refresh test was added and passed afterward.
- No model was retrained or approved, and no remote database migration was performed.
- The 34 reported observation districts omit Mumbai and Mumbai Suburban in this snapshot. Source district names may retain older spellings; do not interpret this as current administrative-boundary validation.

## Village verification and remaining access

Maps now supports versioned source-connection reviews, explicit delivery evidence, expiry and a village coverage checklist. See [remaining data and approximations](REMAINING_DATA_AND_APPROXIMATIONS.md). A separate WRD-branded public feed adds 2,200 mappable reservoir records with an authority-unconfirmed/context-only label. No statewide pipeline/DMA operational feed has been verified.
